# Library Management System

A web-based Library Management System built with PHP and MySQL. It helps library users browse books, borrow and return them, and send book suggestions. Administrators can manage the library collection, user accounts, and borrowing records from a dedicated dashboard.

## Features

- User registration, login, and password reset
- Browse, sort, and view book details by category
- Borrow books with a selected rental duration
- Track borrowed and returned books
- Submit book suggestions and recommendations
- Admin dashboard for managing books, users, borrow records, returns, and suggestions

## Technology Used

- PHP
- MySQL
- HTML, CSS, and JavaScript

## Getting Started

1. Place the project folder in your local PHP server directory, such as `htdocs` when using XAMPP.
2. Create a MySQL database named `library_db`.
3. Import the tables and sample data from `library_db.sql`.
4. Confirm the database connection settings in the PHP files match your local MySQL setup.
5. Start Apache and MySQL, then open `Main.html` in your browser.
